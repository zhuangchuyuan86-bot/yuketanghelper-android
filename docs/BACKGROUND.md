# 后台运行

开始监测时，应用会自动启用前台监测服务和有时限的唤醒保护。无需在应用中另开“高耗电模式”，但 Android 和手机品牌的电池限制仍由系统控制。

## 首次授权

0.2.15 在真实账号监测启动后，自动请求一次 Android 电池优化豁免。在系统窗口允许后，助手更容易保持锁屏网络连接。已授权时跳过，纯演示账号不自动申请；拒绝或关闭窗口仍可继续监测，不会每次启动都弹出。

以后可在“设置 → 后台运行设置 → 允许后台运行”手动申请。按钮与状态读取系统实际结果；应用只记住是否请求过，不会把请求过当成已授权。直接授权页面不可用时，回退至系统电池优化列表或应用信息页。

## vivo / iQOO

“允许后台高耗电”和“自启动”属于品牌系统设置，普通应用没有静默开启它们的公开权限。Android 电池优化豁免与这两个开关相互独立，不能根据系统豁免推断品牌开关已打开。

在手机的后台耗电管理中找到“雨课助手”，允许后台高耗电，并在应用管理中允许自启动。不同 OriginOS 版本入口可能不同，可通过系统设置搜索“后台耗电管理”或“自启动”。助手的“本应用后台设置”可进入应用信息页。

## 使用范围

- 监测期间保持通知可见，不要清理应用后台；每次最长 4 小时。
- 授权不会让应用在监测结束后继续持有唤醒锁，也不会启用开机自启动或自动重新开始监测。
- 系统强制停止或结束进程后，仍需返回助手手动开启监测。
- Android 8.0+ 是兼容目标，本版后台授权窗口、不同 ROM 和覆盖安装尚未实机验证。

本次只增加标准 Android 请求权限及授权入口，未修改课堂连接、自动答题、抢答和作业同步协议。完整检查见 [0.2.15 验证记录](VALIDATION-0.2.15.md)。
