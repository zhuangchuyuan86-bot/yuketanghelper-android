# 扫码登录与长时间等待

适用于 0.2.13，安装版本号 17。

## 正常操作

1. 选择与课程一致的雨课堂站点，打开“微信扫码登录”。
2. 同机操作点“保存二维码到相册”，去微信扫一扫选择刚保存的图，并确认登录；另一台设备也可直接扫码。
3. 回到助手等待“正在验证”和“正在保存”完成。切到微信或登录页面重建时，仍保留同一次登录任务，不自动请求新二维码。
4. 若微信提示过期或助手显示连接结束，点“重新获取二维码”，重新保存并扫描新图。主动刷新会取消原连接，不要再使用先前的相册图。
5. 也可改用网页登录。主动返回、通知中的“取消登录”或等待满 5 分钟会结束本次等待。

## 本次修复

原版每 55 秒请求一个新二维码，相册里的旧图不会跟随刷新。扫码耗时较长时，用户可能确认旧图，而助手已在等待新图。本版取消客户端定时换码，保留对应的连接；每次等待最多 5 分钟。服务器可以更早使二维码失效，应用不能延长其有效期。

原登录协程由 Activity 持有，页面销毁会取消；本版由应用进程持有，登录页仅观察结果。收到确认后，先通过官方接口验证账号并写入原有加密存储，再报告成功。

短时前台服务会在登录期间显示“扫码登录”通知并使用有限唤醒锁，成功、失败、取消或到期时停止。服务不自动重启、不修改课堂监测开关。系统结束进程后需重新扫码，不能保证所有系统均保持后台连接。Android 13 及以上若未允许通知，服务通知可能不出现在常规通知栏；可在应用通知设置允许通知。

## 小米 / Redmi / POCO

按需将雨课助手的应用省电策略设为“无限制”，允许后台活动和后台自启动；系统支持时可在最近任务锁定。选项名称以实际 MIUI / HyperOS 为准。同机扫码期间避免一键清理。若仍失败，可用另一台设备扫码让助手保持前台，并反馈助手显示的失败阶段和数字状态。

## 会话验证失败

- “会话交换”：微信确认结果未能转换为雨课堂会话，请重新获取二维码或尝试网页登录。
- “账号验证”：已有会话但账号查询未完成。临时网络、429 或 5xx 最多尝试 3 次；不重复发送一次性 Auth，明确失效时直接停止。
- “本机保存”：账号验证已完成但手机无法保存，请重试并检查可用存储。
- 提示中不包含 Auth、Cookie、Token 或 API Key。不要在反馈中发送这些信息。

本版尚未进行真实手机、真实账号或模拟器验证，详细自动检查见 [验证记录](VALIDATION-0.2.13.md)。
