**作业提醒**

1. 登录账号，在“课程”勾选要监测的课程并应用选择。
2. 进入“消息 → 作业提醒”，点击“立即同步作业”，查看作业名称、课程、可读取的文字要求及截止时间。点击“查看作业要求”阅读较长文字；“去雨课堂查看”用于完整题目、图片和附件，浏览器可能需要登录。
3. 回总览开始监测后，即使没有正在上课，也会定期检查作业，每轮结束后间隔 5 分钟。停止监测或系统结束进程后，仅保留缓存，可手动同步；每次监测仍最多 4 小时。
4. 首次同步提醒尚未截止的作业；以后提醒新作业及要求、截止时间变更，同一内容不会每轮重复提醒。缓存与消息按雨课堂账号隔离，切换账号查看对应作业。
5. 如需系统通知，开启“通用课程设置 → 本机通知 → 作业”和 Android 通知权限，在“后台运行与机型适配 → 作业提醒通知类别”检查渠道。关闭通知不影响消息页同步。账号未启用监测时的手动同步只更新消息。

截止时间按北京时间显示。同步失败、部分详情不可读取或分页达到限制时会提示，不能根据空白列表判断没有作业。普通作业可能只返回题数、限时等概况；新版练习尽量读取文字要求。每门课程每轮最多检查最近 200 条课程动态，超长要求或超过 30 个题目的部分在官方端查看。详情见 [作业提醒说明](HOMEWORK.md)。

**动态签到限制：本版没有实现动态二维码识别或动态考勤确认。获取连接凭据后显示“已进入课堂；考勤状态请以雨课堂为准”，请以官方端考勤结果为准。详见 [核实记录](DYNAMIC_QR_ATTENDANCE.md)。**

Kotlin 原生 Android 应用，网络、后台和自动操作均在手机上运行，无需桌面 EXE、Python 或中转服务器。最低 Android 8.0（API 26），面向支持 Android APK 的手机和平板。本次 0.2.10 答题提交修复尚未进行实机或模拟器验证。

- 保留接口返回的题目编号类型，避免把字符串编号变成数字。数字编号遇到 HTTP 400 / 50400 参数拒绝时，有条件地在下一次尝试使用同值字符串，仍然最多提交 3 次。
- 每次重试前检查已有答案；第 3 次请求失败后也会复查。确认已有答案时保留现有提交；查询失败或尚未看到答案时继续显示“提交未确认”，请到官方雨课堂核对。

**已有入课编号格式兼容（0.2.8）**

- 数字编号收到 HTTP 400 / 接口代码 50400 时，有条件地改为网页使用的字符串形式再尝试一次；已经是字符串时不重复尝试。账号、站点、编号值和 source 保持一致。

- 失败事件会显示最终的编号格式；只有识别到标准错误文案时才显示固定的校验分类，不记录原文和凭据。50400 不再反复建议重新登录。

**已有入课拒绝诊断（0.2.7）**

- 获取课堂凭据时的 HTTP 400 会立即提示，并展示固定分类及数值接口代码，不再称为课堂消息连接持续中断。
- 已识别的班级权限、入班、身份绑定、动态二维码要求、下课及频率限制分别提示；未知错误保留“具体原因待确认”。
- 入课拒绝每 60 秒重试，同一轮故障每 2 分钟最多提示一次。其他课堂继续接收消息；成功进入前不会产生已入课提示。
- 只限量读取错误响应并提取数字，不记录响应原文、任意服务端文案、Cookie 或 Token。HTTP 非成功响应不会被当作入课成功，明确登录失效仍要求登录。

**已有连接恢复能力（0.2.6）**

- 正常接收消息的课堂连接发生周期性轮换时，在后台自动重连，不再反复显示“课堂连接暂不可用，正在重连”。
- 收到有效题目、点名、弹幕或课堂状态更新后即确认恢复，不要求这次连接先保持 10 秒。安静的课堂可以在连接保持 10 秒后确认恢复。
- 连续 3 次尝试都未恢复消息连接，或重试期间中断达到 15 秒，才显示持续中断提示；同一轮故障每 2 分钟最多一次，恢复时提示一次。
- 未恢复的短连接按 1、2、4、8、16、30 秒退避；正常课堂轮换使用 1 秒间隔。收到 hello 或有效课堂消息可确认就绪；15 秒没有确认则重试，未知消息不算确认。
- 连续连接失败会尝试刷新课堂凭据；主动刷新失败时保留原凭据并尝试重连。WebSocket 明确拒绝的凭据不会用作回退，普通账号接口确认登录失效时仍需重新登录。
- 实际失败会标明获取凭据、连接或处理消息的阶段，区分 HTTP 状态、DNS、连接、超时、TLS、响应格式和缺少凭据。自动操作积压会提示重新同步，不显示任意异常原文或密钥。
- 重连不会重复创建本堂课的自动操作实例，也不会因刷新凭据反复生成进课堂消息。升级会保留原有历史记录，之前的错误提示不会自动删除。

**功能与使用**

- 微信扫码或网页登录；多账号同时监测，以雨课堂站点与用户编号隔离登录、课程选择和消息；AI 配置供全部账号共用。某个账号登录失效会单独停用。
- 每个账号可设置 10–3600 秒的课堂检查间隔，默认 30 秒；在课程页选择监测范围。
- 统一配置单选、多选、投票和主观题的 AI、随机或空白模式；其余题型暂不自动作答。AI 单次上限 20 秒，总预算最多 45 秒，并受题目截止时间约束。无可用 AI 答案时，选择题随机、主观题填一个空格，消息会记录回退。
- 临近截止提交目标为提前约 10–15 秒，未提供截止时间时尽快处理。提交前检查服务器是否已有手动答案；每题最多尝试提交 3 次，最后一次失败后仍复查答案，断线后补题并去重。
- 相同弹幕在滚动 60 秒内达到阈值后跟随发送，同内容 60 秒内最多一次；阈值 1–100，默认 3。红包按编号去重。
- 本机通知与中文语音各自筛选签到、题目、点名、弹幕和红包，所有课程统一使用选择结果。设置页提供语音试听、系统 TTS 入口和后台运行适配入口；通知需手机授权。
- 演示使用模拟课程、答案、弹幕和红包，不请求真实课堂或 AI。首次安装的自动答题、弹幕与红包默认关闭，题目/点名本地通知默认开启。

本项目不集成 PushDeer。

**使用 DeepSeek 等 AI**

1. 进入“设置 → AI 服务与密钥（全局）→ 管理全局 AI 设置 → 添加 AI 密钥”，在“服务商”中选择 DeepSeek，输入名称和 API Key，默认模型 `deepseek-flash`。
2. 多个密钥时在“优先使用”选择所需密钥，点击“保存密钥顺序”。“失败时尝试其他密钥”决定是否依次尝试剩余密钥。
3. 到“设置 → 通用课程设置”，把需要的题型设为 AI 并保存；所有账号共用已配置的全局密钥，再开始监测即可。

支持 DeepSeek、ModelScope 千问与 Google Gemini，可自定义图片模型名。DeepSeek API Key 来自 [开放平台](https://platform.deepseek.com/)，全部雨课堂账号的调用都会使用该 AI 服务账户的 API 余额。密钥请在手机输入。

按 2026-10-16 查阅的 [DeepSeek 图像理解文档](https://api-docs.deepseek.com/zh-cn/guides/vision) 和 [对话接口文档](https://api-docs.deepseek.com/zh-cn/api/create-chat-completion)，默认 `deepseek-flash` 支持图片；`deepseek-v4-pro` 及旧的纯文本模型不能用于课件图片答题。App 调用 `https://api.deepseek.com/chat/completions`，关闭深度思考和流式输出，选择题最多输出 128 tokens，主观题 2048 tokens。截断、过滤或格式无效的答案不提交。

千问发送课件图片 URL；DeepSeek 和 Gemini 先下载本题图片再发送图像内容。下载上限 10 MB，接受 JPEG、PNG 和 WebP；20 秒预算包含下载和推理。停止或超时会取消仍在读取的请求。不增加本地 OCR 模型。

登录和密钥用 Android Keystore / AES-GCM 加密存储，密钥不显示在普通日志、通知或错误文本中。AI 设置页禁用截图，密钥不进入界面状态备份。外部图片与 AI 请求不携带雨课堂会话或课堂 Bearer 凭据，图片下载也不携带 AI Key。应用禁用系统备份和明文 HTTP。

**后台运行与验证**

用户主动启动 dataSync 前台服务，运行时显示持续通知，使用有限时长唤醒锁和 WebSocket 重连。每次最长 4 小时，Android 累计时限与 vivo 省电管理可能提前结束运行。处理系统 onTimeout；进程被系统结束后需手动重新开启。

自动测试使用本地模拟服务和可控时钟，没有消耗真实 AI 余额或提交真实课堂答案。本次 0.2.10 尚未在真实手机或 Android 模拟器运行，也未用真实 DeepSeek Key 测试准确率或延迟。更新后请在官方端核对题目是否收到答案；如仍显示提交未确认，可反馈新提示中的 HTTP 状态、接口代码、编号格式及校验分类。全局 AI 和通用规则保留，无需重新配置。详细结果见 [验证记录](VALIDATION-0.2.10.md)。
